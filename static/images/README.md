# Token artwork

`goblin.png` and `knight.png` were generated with the built-in image generation tool.
They are the default artwork for NPC and PC units respectively.

## Goblin prompt

Use case: stylized-concept. Asset type: square portrait token for a browser tabletop game, displayed at 40x40 pixels. Simple cute cartoony 2D illustration, bold dark outlines, flat colors, very minimal shading, large expressive head with tiny shoulders. Centered front-facing bust, fills most of the square, all important features safely inside a circular crop. Solid pale warm cream background covering the entire square. No text, no letters, no watermark, no border, no scenery, no other characters. Make it immediately readable at tiny sizes. Subject: friendly mischievous green goblin, large pointed ears, round nose, tiny white tusks, brown tunic.
